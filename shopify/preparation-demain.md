# Préparation Shopify — checklist pour demain

## 1. La boutique

- [ ] Créer la boutique (ou utiliser celle qui existe) : nom **Exody**, devise EUR, pays France, langue français.
- [ ] Domaine : acheter **exody.fr** (et exody.com si dispo) et le connecter. Vérifier la disponibilité avant, le nom de la marque en dépend.
- [ ] Thème : un thème gratuit propre suffit au lancement (Sense ou Dawn). Couleurs : fond `#EDE4D3`, texte `#141414`, boutons `#1F3D2B`, accent `#C9A24D`. Polices : Unbounded (titres) + Figtree (texte).
- [ ] Importer `products.csv` (Produits → Importer). Tout arrive en **brouillon** : vérifier chaque fiche, ajouter les photos, puis passer en « Actif ».
- [ ] Installer **Shopify Bundles** (gratuit) pour que les packs laissent choisir les parfums.
- [ ] Créer les collections : Déodorants, Packs, Peau sensible, Nigelle.

## 2. Pages

- [ ] Accueil (structure ci-dessous)
- [ ] La nigelle (reprendre le post 3 et le highlight Nigelle)
- [ ] Comment ça marche (post 5)
- [ ] FAQ (`product/produit-exody.md`)
- [ ] Défi 7 jours (les règles du remboursement)
- [ ] Règlement du concours (avant le 9 octobre)
- [ ] Contact (hello@exody.fr)
- [ ] Mentions légales, CGV, Politique de confidentialité, Livraison et retours : partir des modèles Shopify (Paramètres → Règles) et adapter au droit français : rétractation 14 jours, médiateur de la consommation, personne responsable du produit cosmétique.

## 3. Paiement, livraison, taxes

- [ ] Shopify Payments + PayPal.
- [ ] Livraison France : Colissimo et Mondial Relay. **Gratuite dès 35 €**, sinon 4,90 €. Belgique / Suisse plus tard.
- [ ] TVA 20 % incluse dans les prix.
- [ ] Code promo **EXODY15** : -15 %, première commande uniquement, valable jusqu'au dimanche 27 septembre inclus (prolongeable).

## 4. Applications
