# Version Maroc — petits pots et vente au Maroc

Ce dossier **remplace** ce qui est dit ailleurs dans le dépôt sur le format, les prix, la fabrication et la logistique. Le reste (identité, ton, posts, highlights) reste valable, avec les adaptations listées dans `instagram-maroc.md`.

Ce qui change :

| | Version France (dossiers `product/`, `shopify/`) | Version Maroc (ce dossier) |
|---|---|---|
| Format | Pot 50 g, 3 mois | **Petit pot rond 20 g style K-beauty**, ≈ 6 semaines |
| Fabrication | Façonnier en France | **Façonnier au Maroc** (« Fabriqué au Maroc ») |
| Prix | 12,90 € | **79 DH** le pot, packs 139 / 199 / 299 DH |
| Paiement | Carte | **Paiement à la livraison** + carte CMI |
| Livraison | Colissimo | Ozon Express / Cathedis / Amana, 30 à 40 DH, offerte dès 199 DH |
| Réglementation | DIP + CPNP (UE) | **Enregistrement AMMPS / DMP** (circulaire 48 DMP/20) |
| Domaine | exody.fr | **exody.ma** |
