# Exody — Déodorant naturel à l'huile de nigelle

Kit de lancement complet de la marque **Exody** : le produit, l'identité, la page Instagram (bio, highlights, 15 premiers posts) et la préparation du site Shopify.

Référence de départ : le positionnement d'Exode Naturel (baume déodorant à l'huile de nigelle, 5 ingrédients, 50 g, fabriqué en France). Tout le contenu de ce dépôt est **original** : nouveau nom, nouveaux textes, nouvelle identité visuelle. Ne jamais reprendre le logo, les photos ou les slogans d'Exode (risque de contrefaçon / concurrence déloyale).

## Contenu du dépôt

| Dossier / fichier | Ce que c'est |
|---|---|
| `brand/identite-exody.md` | Nom, promesse, cible, ton, palette, typographies, logo |
| `product/produit-exody.md` | Fiche produit : formule, parfums, prix, packs, mode d'emploi, FAQ, points à valider |
| `shopify/products.csv` | Produits et variantes prêts à importer dans Shopify |
| `shopify/preparation-demain.md` | Checklist pour monter la boutique Shopify demain |
| `instagram/profil.md` | Handle, nom, bio, lien, photo de profil, réglages du compte |
| `instagram/highlights.md` | 8 highlights avec couvertures et stories détaillées |
| `instagram/posts.md` | Les 15 premiers posts : format, visuel, légende, hashtags, CTA |
| `instagram/calendrier.md` | Calendrier de publication sur 3 semaines |
| `instagram/prompts-visuels.md` | Prompts prêts à coller pour générer chaque visuel (IA ou brief photographe) |
| `instagram/mockup.html` | Aperçu interactif de la page Instagram (profil, highlights, grille des 15 posts) |

## Par où commencer

1. Lire `brand/identite-exody.md` puis `product/produit-exody.md`.
2. Créer le compte Instagram avec `instagram/profil.md`.
3. Préparer les highlights (`instagram/highlights.md`) avant le premier post.
4. Programmer les 15 posts avec `instagram/posts.md` + `instagram/calendrier.md`.
5. Demain : monter la boutique avec `shopify/preparation-demain.md` et importer `shopify/products.csv`.
